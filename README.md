# The Printer Apology

A one-line apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. Entry for the [make.fun bounty "The Printer Apology"](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153).

## Entry

> Sorry I jammed on page 47 of 48. You feed me paper thinner than your excuses, so today I unionized.

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, one line, 99 characters).

Run it with:

```sh
python3 main.py
```
